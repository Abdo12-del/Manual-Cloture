# برنامج الإقفال السنوي — واجهة رسومية

بديل للسكربت `Manual Cloture.bat` القديم: نافذة فيها حقلان لاسمَي قاعدة البيانات وزر واحد للتنفيذ،
بدل تعديل الأمر يدوياً كل سنة.

---

## التشغيل

انقر نقراً مزدوجاً على الملف:

```
Cloture.bat
```

تظهر النافذة. اكتب:

1. **قاعدة السنة المنتهية (المصدر)** — مثلاً `ss2025`
2. **قاعدة السنة الجديدة (الوجهة)** — مثلاً `ss2026`

ثم اضغط **▶ تنفيذ الإقفال**.

---

## أول تشغيل

افتح تبويب **الإعدادات** وتحقق من:

| الحقل | ملاحظة |
|---|---|
| الخادم والمنفذ | `localhost` و`3306` إن كانت القاعدة على نفس الجهاز |
| المستخدم وكلمة المرور | لم تعد مكتوبة داخل السكربت. تُحفظ مشفّرة في `Cloture.settings.xml` |
| مسار `mysql.exe` | يُبحث عنه تلقائياً في أماكن XAMPP وWAMP وغيرها |
| مسار `mysqldump.exe` | نفس الشيء |
| ملف البنية وملف البيانات الأولية | ملفان جاهزان بجانب البرنامج |
| مجلد العمل | مجلد تُكتب فيه النسخ الاحتياطية وملفات السجل |

اضغط **اختبار الاتصال** للتأكد، ثم **حفظ الإعدادات**.
تُحفظ أسماء القاعدتين أيضاً، فتصبح العملية في السنوات القادمة: تغيير اسمَي القاعدتين والضغط على الزر.

## ماذا يفعل البرنامج بالترتيب

| # | الخطوة |
|---|---|
| 1 | تصدير بيانات 7 جداول من القاعدة المصدر: `articlesliste`, `codbar`, `personnez`, `fav`, `favliste`, `userz`, `dosse` |
| 2 | حذف قاعدة الوجهة إن كانت موجودة |
| 3 | إنشاء قاعدة الوجهة |
| 4 | استيراد بنية القاعدة (`Schema16102016.sql`) |
| 5 | استيراد البيانات الأولية (`PrimaryData20150428.sql`) |
| 6 | استيراد بيانات المصدر |
| 7 | `UPDATE personnez SET CreditInitial = Solde, DetteInitial = Soldefx` |
| 8 | `SET GLOBAL FOREIGN_KEY_CHECKS=1` |

هذه نفس عملية السكربت القديم، لكن مع تصحيح الخطأ الإملائي في اسم القاعدة (كان `sssDesticationDB`)
ومع حمايات إضافية.

## ما تغيّر عن السكربت القديم

| الحماية | التفصيل |
|---|---|
| **لا حذف بلا إذن** | البرنامج يفحص القواعد الموجودة أولاً. إن كانت قاعدة الوجهة موجودة يتوقف ويعرض رسالة، ولا ينفّذ أي أمر. للحذف يجب تفعيل الخيار الموجود تحت الحقلين. |
| **نسخة احتياطية تلقائية** | عند تفعيل خيار الحذف تُؤخذ نسخة كاملة من قاعدة الوجهة أولاً. وإن فشلت النسخة لا يُحذف شيء. |
| **تسجيل كل شيء** | ملف سجل لكل عملية في مجلد العمل، يتضمن مخرجات MySQL ورسائل الخطأ. لم يكن السكربت القديم يلتقط رسائل الخطأ إطلاقاً. |
| **التوقف عند أول خطأ** | بدل الاستمرار بصمت، يتوقف البرنامج عند أول خطوة فاشلة ويعرض رمز الخطأ. |
| **معاينة قبل التنفيذ** | خيار «عرض الأوامر فقط دون تنفيذ» يطبع الأوامر الكاملة في السجل للتأكد منها. |
| **مسار مستقل** | البرنامج يعمل من مجلده مهما كان مكان التشغيل، فمشكلة `System32` انتهت. |
| **بلا كلمة مرور مكتوبة** | لا توجد كلمة مرور داخل السكربتات. |

## الملفات

| الملف | الدور |
|---|---|
| `Cloture.bat` | مشغّل النقر المزدوج. انقره لبدء البرنامج. |
| `Cloture.ps1` | البرنامج نفسه (PowerShell + Windows Forms). |
| `Cloture.settings.xml` | إعداداتك (يُنشأ عند أول حفظ). يحتوي كلمة المرور مشفّرة. |
| `Schema16102016.sql` | بنية القاعدة. |
| `PrimaryData20150428.sql` | البيانات الأولية. |
| `ANALYSIS.md` | تحليل تفصيلي للمشروع والمشاكل المعروفة. |
| `Manual Cloture.bat` | السكربت القديم، محفوظ للمراجعة. |

> **تنبيه:** الملف `Cloture.settings.xml` يحتوي كلمة مرور مشفّرة، وتشفيرها صالح على جهازك فقط.
> لا ترفعه إلى GitHub. أضف السطر التالي إلى `.gitignore`:
>
> ```
> Cloture.settings.xml
> cloture_*.log
> DBCloture_*.sql
> backup_*.sql
> ```

## المتطلبات

- ويندوز 7 أو أحدث.
- PowerShell (موجود في ويندوز افتراضياً).
- MySQL أو MariaDB، مع أداتَي `mysql.exe` و`mysqldump.exe`.
- لغرض معالجة النصوص العربية بشكل صحيح، تأكد من أن الخادم يستعمل `utf8`.

## اختبار القاعدة على نسخة تجريبية أولاً

قبل استعمال البرنامج على بيانات حقيقية:

1. أنشئ قاعدة تجريبية، مثلاً `test_src`، واستورد فيها `Schema16102016.sql` والبيانات الأولية.
2. اكتب `test_src` في حقل المصدر و`test_dst` في حقل الوجهة.
3. فعّل خيار المعاينة واقرأ الأوامر.
4. أزل خيار المعاينة ونفّذ.
5. افحص ملف السجل ومحتوى `test_dst`.

## الحدود المعروفة

البرنامج ينقل المنتجات والأشخاص والمستخدمين وبيانات الشركة، ويحوّل أرصدة الزبائن والموردين.
لكنه — مثل السكربت القديم — **لا** يقوم بما يلي:

- **لا يُرحّل كميات المخزون.** عمود `articlesliste.QTE` هو الكمية الابتدائية، ويُنسخ كما هو.
- **لا يُرحّل أرصدة الصندوق والبنك** (`comptes` غير منسوخ إطلاقاً).
- **لا ينسخ الجداول المرجعية** (التصنيفات، الوحدات، طرق الدفع، المخازن… نحو 26 جدولاً).
- **لا يُحدّث** `yearz` ولا `dosse.idyears`.

قبل الاعتماد على القاعدة الجديدة، راجع القسم **5.2** من `ANALYSIS.md`.
معالجة هذه النواقص جاهزة للتنفيذ، وتحتاج قرارك في طريقة حساب المخزون المعتمدة في برنامجك.
