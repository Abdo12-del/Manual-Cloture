# برنامج الإقفال السنوي — نسخة حقيقية قابلة للتشغيل

برنامج فعلي بواجهة رسومية لتنفيذ **الإقفال السنوي** (Clôture de l'exercice)
لقاعدة بيانات MySQL الخاصة ببرنامج gamadev.

يعمل البرنامج ضد أي خادم MySQL/MariaDB حقيقي، ومعه **خادم MySQL تجريبي مدمج**
حتى يمكنك تجربة العملية كاملة قبل تطبيقها على بياناتك.

---

## التشغيل

### على هذا الخادم (معاينة حية)

البرنامج يعمل الآن ويمكن فتحه من المعاينة. عند فتح الواجهة يكون **حقلا القاعدتين فارغين** —
اكتب أسماء القواعد ثم اضغط التنفيذ.

### على جهازك (ويندوز/لينكس/ماك)

```bash
cd web
npm install
npm start
```

ثم افتح المتصفح على `http://localhost:3000`.

المتطلبات: Node.js 18 أو أحدث. لا يحتاج أي شيء آخر — حتى خادم MySQL التجريبي مدمج في البرنامج.

---

## أول تشغيل

1. افتح البرنامج — تظهر واجهة فارغة (حقلا «المصدر» و«الوجهة» فارغان).
2. لتجربة البرنامج بدون بيانات حقيقية: اضغط **«تجهيز بيانات التجربة (ss2025)»** —
   يُنشأ خادم MySQL تجريبي (على المنفذ 3306 محليًا) وفيه قاعدة `ss2025`
   ببنية المخطط الحقيقية (77 جدولًا) وبيانات تجريبية: 25 منتجًا، 23 شخصًا (زبائن وموردون بأرصدة)،
   مستخدمون، أكواد بار، مفضلة نقطة البيع.
3. اكتب `ss2025` في **المصدر** و`ss2026` في **الوجهة** واضغط **▶ تنفيذ الإقفال**.
4. تابع السجل خطوة بخطوة، وبعد الانتهاء افحص ملفات التصدير والنسخ الاحتياطي والسجل في مجلد `web/work`.

للعمل على قاعدتك الحقيقية: افتح تبويب **الإعدادات**، غيّر الخادم/المنفذ/المستخدم/كلمة المرور،
اضغط **اختبار الاتصال** ثم **حفظ الإعدادات**.

## ماذا يفعل البرنامج بالترتيب (8 خطوات)

| # | الخطوة |
|---|---|
| 1 | تصدير بيانات 7 جداول من المصدر: `articlesliste`, `codbar`, `personnez`, `fav`, `favliste`, `userz`, `dosse` |
| 2 | حذف قاعدة الوجهة إن كانت موجودة (بعد إذن صريح + نسخة احتياطية) |
| 3 | إنشاء قاعدة الوجهة بترميز utf8 |
| 4 | استيراد بنية القاعدة (`Schema16102016.sql` — 77 جدولًا + الدوال والإجراءات) |
| 5 | استيراد البيانات الأولية (`PrimaryData20150428.sql`) |
| 6 | استيراد بيانات المصدر المصدّرة |
| 7 | `UPDATE personnez SET CreditInitial = Solde, DetteInitial = Soldefx` |
| 8 | `SET GLOBAL FOREIGN_KEY_CHECKS=1` |

هذه نفس عملية السكربت القديم `Manual Cloture.bat` مع تصحيح خطأه الإملائي
(`sssDesticationDB`) ومع الحمايات أدناه.

## الحمايات

| الحماية | التفصيل |
|---|---|
| **لا حذف بلا إذن** | إن كانت قاعدة الوجهة موجودة يتوقف البرنامج قبل تنفيذ أي أمر. الحذف يتطلب تفعيل خانة «اسمح بحذف قاعدة الوجهة». |
| **نسخة احتياطية تلقائية** | عند السماح بالحذف تُؤخذ نسخة كاملة من قاعدة الوجهة أولًا، وإن فشلت لا يُحذف شيء. |
| **معاينة بدون تنفيذ** | خانة «عرض الأوامر فقط دون تنفيذ» تعرض خطة العمل كاملة في السجل. |
| **إيقاف عند أول خطأ** | يتحقق من وجود قاعدة المصدر قبل أي شيء، ويتوقف عند أول خطوة فاشلة مع تفاصيل الخطأ. |
| **سجل كامل** | ملف سجل لكل عملية في `web/work` مع ملف تصدير `.sql` قابل لإعادة الاستعمال. |
| **إلغاء أثناء العمل** | زر إلغاء يوقف العملية فورًا. |
| **بلا كلمة مرور في الكود** | بيانات الاتصال في `web/cloture-settings.json` (لا يُرفع إلى Git). |

## الخادم التجريبي المدمج

`web/mysql-server.js` خادم يتحدث **بروتوكول MySQL الحقيقي** (handshake v10،
`mysql_native_password`، حزم نتائج قياسية)، أي يتصل به أي عميل MySQL: `mysql2`،
`mysql` CLI، phpMyAdmin… المحرك خلفه `SQLite` مع مترجم أوامر
(`CREATE TABLE` مع كل أنواع MySQL، `AUTO_INCREMENT`، `b'0'`، `0x1F`،
`DELIMITER ;;`، أجسام الإجراءات والدوال…) — يكفي لتشغيل مخطط gamadev
كاملًا وتجربة الإقفال من البداية للنهاية.

| المنفذ | الخدمة |
|---|---|
| 3000 | واجهة البرنامج + API |
| 3306 | خادم MySQL التجريبي (يتغير تلقائيًا إلى 3307 إن كان مشغولًا) |

## الحدود المعروفة (نفس السكربت الأصلي)

البرنامج ينقل المنتجات والأشخاص والمستخدمين وبيانات الشركة ويحوّل الأرصدة، لكنه:

- **لا يُرحّل كميات المخزون** (`articlesliste.QTE` تُنسخ كما هي).
- **لا يُرحّل أرصدة الصندوق والبنك** (`comptes` غير منسوخ).
- **لا ينسخ الجداول المرجعية** (نحو 26 جدولًا).
- **لا يُحدّث** `yearz` ولا `dosse.idyears`.

راجع القسم **5.2** من `ANALYSIS.md` قبل الاعتماد على القاعدة الجديدة.

> **تنبيه:** `web/cloture-settings.json` يحتوي بيانات الاتصال — لا ترفعه إلى GitHub
> (مستثنى في `.gitignore`).
